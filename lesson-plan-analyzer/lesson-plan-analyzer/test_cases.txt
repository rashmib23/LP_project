================================================================================
                            ISSUES / OBSERVATIONS
================================================================================

  1. TC-25  -- Strategy labels include the suffix "-based" (e.g.
              "Lecture-based") in API responses. Either accept this in the
              spec, or strip the suffix in routes/lessons.py before
              returning. Functional impact: none; cosmetic only.

  2. TC-44  -- BOM stripping works only when the CSV is saved as
              "CSV UTF-8 (Comma delimited)" in Excel. The default
              "CSV (Comma delimited)" does NOT add a BOM, so the test is
              inherently format-dependent and should call this out in
              the test-data column.

  3. TC-47  -- Missing "score" column does not raise an error; rows are
              saved with score=0 because of the lenient default in
              routes/performance.py:
                 score=float(row.get("score") or 0)
              Recommend a stricter mode that fails the row when the
              header is absent, mirroring the lesson_plan_id behavior.
