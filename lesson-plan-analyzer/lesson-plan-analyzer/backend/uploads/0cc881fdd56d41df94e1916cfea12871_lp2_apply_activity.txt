------------------------------------------------------------
1. LEARNING OBJECTIVES
------------------------------------------------------------
By the end of this lesson, students will be able to:
  a) Apply CREATE TABLE, ALTER TABLE, and DROP TABLE DDL commands.
  b) Use INSERT, UPDATE, DELETE, and SELECT DML statements on a live database.
  c) Construct SQL queries using WHERE, ORDER BY, GROUP BY, and HAVING clauses.
  d) Execute JOIN operations (INNER, LEFT) to retrieve data from multiple tables.
  e) Demonstrate the use of aggregate functions (COUNT, SUM, AVG, MAX, MIN).

Bloom's Level : Apply (a–e)

  - Relational model: tables, rows, columns, primary and foreign keys (Unit I)
  - ER diagrams and schema mapping (Unit I Lab)

------------------------------------------------------------
3. CONTENT OUTLINE
------------------------------------------------------------

3.1 Quick Revision – DDL Commands (10 min)
    • CREATE TABLE with data types (INT, VARCHAR, DATE, DECIMAL).
    • Constraints: PRIMARY KEY, NOT NULL, UNIQUE, DEFAULT, FOREIGN KEY.
    • ALTER TABLE: ADD COLUMN, MODIFY COLUMN, DROP COLUMN.
    • DROP TABLE vs TRUNCATE TABLE.

3.2 DML – INSERT, UPDATE, DELETE (15 min)
    • INSERT INTO … VALUES (single and multi-row).
    • UPDATE … SET … WHERE (importance of WHERE to avoid full-table update).
    • DELETE FROM … WHERE.
    • Transaction safety: COMMIT and ROLLBACK (brief mention).

3.3 SELECT with Clauses (15 min)
    • SELECT with WHERE (comparison, logical operators, BETWEEN, IN, LIKE).
    • ORDER BY (ASC / DESC).
    • GROUP BY with aggregate functions.
    • HAVING vs WHERE for filtering groups.

3.4 JOINs (10 min)
    • INNER JOIN: returns matching rows from both tables.
    • LEFT JOIN: all rows from left table + matched rows from right.
    • Practical: retrieve employee name + department name from two tables.

3.5 Hands-on Activity (35 min)
    Students log into MySQL Workbench (pre-installed on lab machines).
    They are given the "College Database" schema (Students, Courses,
    Enrollments, Faculty tables) and complete the following worksheet tasks:

    Task 1: Create the Enrollments table with appropriate constraints.
    Task 2: Insert 5 student records and enrol them in two courses.
    Task 3: Write a SELECT query to list all students enrolled in 'DBMS'
            ordered by their roll number.
    Task 4: Find the average marks per course using GROUP BY and HAVING
            to show only courses where average > 60.
    Task 5: Use a LEFT JOIN to list all students and their enrolled course
            (show NULL for students with no enrolment).

    Students work individually; instructor circulates and assists.

3.6 Debrief and Common Errors (5 min)
    • Display the most common errors observed during the activity on screen.
    • Ask one student to present their Task 4 query and explain it.

------------------------------------------------------------
4. TEACHING METHODS AND STRATEGIES
------------------------------------------------------------

  Method 1 – Demonstration (25 min)
    Instructor demonstrates each SQL command live in MySQL Workbench
    on the projected screen, showing the output of each query immediately.
    Students are encouraged to replicate commands on their own machines.

  Method 2 – Activity-Based / Hands-on Practice (35 min)
    Students work through the five worksheet tasks on their own lab machines.
    The worksheet is distributed as a printed sheet and also posted on LMS.
    Hands-on exercises reinforce command syntax through practice and immediate feedback.

  Method 3 – Drill and Immediate Feedback (10 min)
    Instructor circulates during the activity, correcting syntax errors on
    the spot. Targeted verbal feedback given to each student or pair.

  Method 4 – Discussion (10 min)
    Whole-class debrief: a student presents Task 4; peers critique the query
    and suggest improvements. Instructor summarises common mistakes.

------------------------------------------------------------
5. ASSESSMENT STRATEGY

  Formative:
    • Worksheet completion during lab (observed by instructor).
