3. CONTENT OUTLINE
------------------------------------------------------------

3.1 What is a Data Structure? (10 min)
    • Definition: a way of organizing and storing data in a computer so that
      it can be accessed and modified efficiently.
    • Classification: linear (arrays, stacks, queues, linked lists) and
      non-linear (trees, graphs).
    • Importance: choosing the right structure determines program efficiency.

3.2 Arrays (15 min)
    • Definition: a collection of elements of the same type stored in
      contiguous memory locations.
    • Indexing: zero-based in C; array A of size n has indices 0 to n-1.
    • Declaration: int A[10]; — reserves 10 integer slots.
    • Operations: access (A[i]), update (A[i]=val), traverse.
    • Limitation: fixed size, insertion/deletion costly.

3.3 Stacks (15 min)
    • Definition: a linear data structure that follows the
      Last-In First-Out (LIFO) principle.
    • Real-world analogy: stack of plates — last plate placed is first removed.
    • Components: top pointer, base.
    • Basic operations: PUSH (insert), POP (delete), PEEK (view top), isEmpty.
    • Applications: function call stack, undo operations, expression evaluation.

3.4 Queues (15 min)
    • Definition: a linear structure following First-In First-Out (FIFO).
    • Real-world analogy: people waiting in a ticket queue.
    • Components: front pointer, rear pointer.
    • Basic operations: ENQUEUE (insert at rear), DEQUEUE (remove from front).
    • Variants (names only): Circular queue, Priority queue, Deque.

3.5 Recap and Q&A (5 min)
    • Oral recall: students name one real-world use of a stack and a queue.

------------------------------------------------------------
4. TEACHING METHODS AND STRATEGIES
------------------------------------------------------------

  Method 1 – Lecture with Slides (40 min)
    The instructor will deliver a lecture using prepared slides covering
    all three data structures. Each concept is introduced with its formal
    definition, followed by a diagram on the blackboard. Students are
    expected to take notes.

  Method 2 – Whiteboard Demonstration (15 min)
    The instructor will draw memory diagrams for an array of size 5,
    step through PUSH and POP operations on a stack of size 4, and
    illustrate ENQUEUE/DEQUEUE on a queue using boxes on the board.

  Method 3 – Verbal Questioning (5 min)
    The instructor will call on students randomly to recall definitions
    and identify the correct data structure for simple scenarios read aloud.
